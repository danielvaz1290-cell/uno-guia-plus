# UNO Guia+

Protótipo interativo de orientação para bolsas estudantis, com questionário e checklist personalizado.

## Como acessar
Depois que o workflow do GitHub Pages concluir a publicação, o site ficará disponível em:

https://danielvaz1290-cell.github.io/uno-guia-plus/

## Importante
Este é um protótipo de demonstração. As orientações e regras precisam ser revisadas e validadas pela Unochapecó antes de qualquer uso institucional. O protótipo não substitui o Minha UNO nem a análise oficial do Setor de Bolsas.

## Publicação
O site é estático e publicado pelo GitHub Actions com GitHub Pages. Cada atualização enviada à branch `main` inicia uma nova publicação.
